# Demonstration video script (five minutes or less)

**0:00–0:25 — Context**  
“This is Design and Development of a Classical Cryptography Toolkit for Network Security, ECM 2026–27. It is an educational tool, not a replacement for modern cryptography.”

**0:25–1:20 — Dashboard**  
Show the real session counters, cipher list, and security notice. Explain that empty metrics are not fabricated until operations are performed.

**1:20–2:25 — Live workspace**  
Choose Caesar, enter `NETWORK SECURITY`, key `5`, and encrypt. Confirm `SJYBTWP XJHZWNYD`; decrypt it back. Switch to Playfair `MONARCHY`, run `INSTRUMENTS`, and point at the live 5×5 square and filler note.

**2:25–3:15 — Other mechanics**  
Show Hill with `HILL`, Vigenère alignment, and Rail Fence rows. Mention that each visualization is returned from the same backend computation.

**3:15–4:00 — Compare and files**  
Select four algorithms, run the repeated median benchmark, and explain that runtime is not security. Upload `samples/sample_plaintext.txt`, preview it, and download an encrypted text result.

**4:00–4:35 — History and help**  
Show session-only history, then Help & documentation. Point out that messages and keys are intentionally excluded.

**4:35–5:00 — Close**  
“The project demonstrates classical transformations with validated inputs, actual REST operations, automated tests, and clear limits. Modern confidential data still requires modern, reviewed cryptographic systems.”
